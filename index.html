Roadmap Setup ZeroCores Server

Ikuti tahap (stage) di bawah ini secara berurutan agar setup server berjalan dari nol sampai siap dibuka untuk publik tanpa error.

STAGE 1

Setup Panel & Environment Core

Persiapan awal pada LavaHosting Pterodactyl Panel sebelum memasukkan plugin.

  • Java Version: Pastikan menggunakan Java 25 / Java 21 di tab Startup Panel.
  • Startup Command: java -Xms128M -XX:MaxRAMPercentage=95.0 -Dterminal.jline=false -Dterminal.ansi=true -jar server.jar
  • Folder Initialization: Jalankan server 1x untuk generate folder /plugins/ dan server.properties (set online-mode=false).
STAGE 2

Inisialisasi World & Multiverse

Membuat struktur dunia dasar ZeroNest.

CONSOLE Perintah Inisialisasi World
mv create Survival normal
mv create Survival_nether nether
mv create Survival_the_end end
mv create Medieval normal
mv create Fishing normal -g VoidGen
STAGE 3

Pembangunan Lobby & Proteksi Region

Paste schematic Lobby utama dan kunci proteksi pvp & break.

PLAYER WorldEdit & WorldGuard Lobby
//schem load lobby_zero_nest
//paste -s
//pos1
//pos2
/rg define lobby_protect
/rg flag lobby_protect pvp deny
/rg flag lobby_protect mob-spawning deny
/rg flag lobby_protect block-break deny
STAGE 4

Pemasangan Interaksi NPC & Hologram

Membuat NPC penghubung ke masing-masing mode dan papan hologram.

PLAYER Interaksi Navigation
/npc create medivalrpg
/npc displayname medivalrpg &c&l⚔ MEDIEVAL RPG
/npc action medivalrpg add RIGHT_CLICK player_command mv tp %player% Medieval

/dh create lobby_welcome
/dh line add lobby_welcome &5&lZERONEST
/dh line add lobby_welcome &dSelamat datang di ZeroNest
STAGE 5

Hirarki Ranks, Permission & Isolasi World

Membuat rank dasar dan mengunci plugin pancingan/RPG agar tidak bocor ke Survival Economy.

CONSOLE Setup Rank LuckPerms
/lp creategroup zero
/lp creategroup zerocores
/lp group zerocores parent add zero

/lp group zero permission set essentials.sethome true
/lp group zero meta setsethome.multiple.default 3
/lp group zero permission set abyssal-fishing.use false world=Survival
STAGE 6

Konektivitas Crossplay Bedrock & Pre-Generation

Mengaktifkan Geyser/Floodgate serta pre-render chunk agar server tidak lag.

CONSOLE Pre-gen World Survival
chunky world Survival
chunky radius 2000
chunky start

Multiverse-Core

Inti Fungsi: Pengelola dan pembuat dunia (world) di server.

🎮 Tutorial In-Game (Command)

/mv tp Survival | /mv setspawn | /mv load Medieval | /mv unload Medieval

⚙️ Tutorial Panel (Config / Pterodactyl)

Edit file /plugins/Multiverse-Core/worlds.yml untuk mengubah pvp/gamemode default world.

LuckPerms

Inti Fungsi: Pengatur hak akses, rank, dan permission player/staff.

🎮 Tutorial In-Game (Command)

/lp user [player] group set zerocores | /lp group zero permission set [node] true

⚙️ Tutorial Panel (Config / Pterodactyl)

Buka editor visual via web dengan perintah console: /lp editor lalu simpan link yang diberikan.

FancyNpcs

Inti Fungsi: NPC visual interaktif untuk teleportasi player.

🎮 Tutorial In-Game (Command)

/npc create survival | /npc displayname survival &a&l⚔ SURVIVAL | /npc action survival add RIGHT_CLICK player_command mv tp %player% Survival

⚙️ Tutorial Panel (Config / Pterodactyl)

Lokasi data NPC tersimpan di /plugins/FancyNpcs/config.json.

AbyssalFishing

Inti Fungsi: Sistem pancingan custom dan pasar jual ikan khusus di world Fishing.

🎮 Tutorial In-Game (Command)

/abyssalfishing reload | /abyssalfishing sellall

⚙️ Tutorial Panel (Isolasi & Config)

Edit /plugins/AbyssalFishing/config.yml dan isi disabled-worlds: ["Survival", "Lobby", "Medieval"].

Geyser-Spigot & Floodgate

Inti Fungsi: Menghubungkan player Minecraft Bedrock (Android/iOS) ke Java server.

🎮 Tutorial In-Game (Command)

/geyser reload | /geyser connectiontest

⚙️ Tutorial Panel (Port & Security)

Buka /plugins/Geyser-Spigot/config.yml, atur port: 19132 (Port UDP LavaHosting) dan pastikan file /plugins/Floodgate/key.pem tidak dihapus.

Panduan Isolasi Plugin Per-World

Cara memastikan plugin pancingan, RPG, dan klaim tanah **MATI TOTAL** di world yang tidak seharusnya.

CONFIG /plugins/AbyssalFishing/config.yml
disabled-worlds:
  - "Survival"
  - "Survival_nether"
  - "Survival_the_end"
  - "Lobby"
  - "Medieval"
  - "bskyblock_world"
  - "aoneblock_world"
CONSOLE Command LuckPerms Isolation
/lp group zero permission set abyssal-fishing.use false world=Survival
/lp group zero permission set auraskills.use false world=Survival
/lp group zero permission set griefprevention.claims false world=Medieval

Pilih Mode Permainan:

⚔️ Survival Economy

Dunia survival vanila + klaim lahan (GriefPrevention), toko GUI, auction house, dan RTP.

🛡️ Medieval RPG

Dunia dark fantasy tanpa Nether/End, pertarungan Boss MythicMobs, dan skill AuraSkills.

🎣 Abyssal Fishing

Dunia pancingan terisolasi ber-type VoidGen dengan ekonomi penjualan ikan kustom.

☁️ SkyBlock (BSkyBlock)

Pulau melayang yang dikelola penuh oleh BentoBox Addon.

⛏️ OneBlock (AOneBlock)

Game mode dari 1 blok beregenerasi beserta LuckyBlock progression.
