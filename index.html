Arsitektur Jaringan ZeroNest

Seluruh sistem server ZEROCORES berpusat pada Lobby utama bernama ZeroNest. Player Java dan Bedrock terkoneksi melalui satu instance Paper Server 1.21.x dengan struktur world terisolasi.

Struktur Direktori World ZeroNest
ZEROCORES (Paper 1.21.x / Java 25)
│
├── Lobby (World: Lobby) ➔ [Spawn Utama & NPC Navigation]
│
├── Survival Economy
│   ├── Survival (World: Survival)
│   ├── Survival_Nether (World: Survival_nether)
│   └── Survival_TheEnd (World: Survival_the_end)
│
├── Medieval RPG
│   └── Medieval (World: Medieval) ➔ [No Nether/End]
│
├── Fishing
│   └── Fishing (World: Fishing) ➔ [No Nether/End]
│
├── SkyBlock (Managed via BentoBox)
│   ├── SkyBlock (World: bskyblock_world)
│   └── SkyBlock_Nether (World: bskyblock_world_nether)
│
└── OneBlock + LuckyBlock (Managed via BentoBox)
    ├── OneBlock (World: aoneblock_world)
    └── OneBlock_Nether (World: aoneblock_world_nether)

Cara Isolasi Plugin Agar Tidak Ikut ke World Lain

Fitur seperti AbyssalFishing, MythicMobs, atau AuraSkills hanya boleh berjalan di world khusus (misal: Fishing atau Medieval) dan MATI TOTAL di Survival Economy.

1. Isolasi via Config YAML (`disabled-worlds`)

A. AbyssalFishing (Hanya di World Fishing)

Edit file /plugins/AbyssalFishing/config.yml:

CONFIG /plugins/AbyssalFishing/config.yml
disabled-worlds:
  - "Survival"
  - "Survival_nether"
  - "Survival_the_end"
  - "Lobby"
  - "Medieval"
  - "bskyblock_world"
  - "aoneblock_world"

B. AuraSkills (Hanya di World Medieval)

Edit file /plugins/AuraSkills/config.yml:

CONFIG /plugins/AuraSkills/config.yml
disabled-worlds:
  - "Survival"
  - "Survival_nether"
  - "Survival_the_end"
  - "Lobby"
  - "Fishing"
  - "bskyblock_world"
  - "aoneblock_world"

C. MythicMobs (Hanya di World Medieval)

Edit file /plugins/MythicMobs/config.yml:

CONFIG /plugins/MythicMobs/config.yml
General:
  DisabledWorlds:
  - Survival
  - Survival_nether
  - Survival_the_end
  - Lobby
  - Fishing
  - bskyblock_world
  - aoneblock_world

2. Isolasi Command & Permission via LuckPerms World Context

Jalankan perintah berikut di Console Pterodactyl untuk mematikan akses command plugin tertentu khusus di world Survival atau World lain:

CONSOLE LuckPerms Context Execution
# Matikan command AbyssalFishing di World Survival
/lp group zero permission set abyssal-fishing.use false world=Survival

# Matikan command AuraSkills di World Survival & Lobby
/lp group zero permission set auraskills.use false world=Survival
/lp group zero permission set auraskills.use false world=Lobby

# Matikan GriefPrevention Claim di World Medieval & Fishing (Hanya Boleh di Survival)
/lp group zero permission set griefprevention.claims false world=Medieval
/lp group zero permission set griefprevention.claims false world=Fishing
/lp group zero permission set griefprevention.claims false world=Lobby

Operasional Panel Pterodactyl via HP

Tutorial mengelola server secara nyaman menggunakan browser mobile tanpa PC.

Parameter Startup Utama

Startup Flags (LavaHosting)
java -Xms128M -XX:MaxRAMPercentage=95.0 -Dterminal.jline=false -Dterminal.ansi=true -jar server.jar

Prosedur Pengelolaan File via Pterodactyl Mobile

  1. Upload Plugin/World: Akses menu File Manager ➔ Navigasi ke folder target (contoh: /plugins) ➔ Tekan tombol Upload. Jika file besar (.zip world), ekstrak menggunakan fitur Unarchive bawaan Pterodactyl.
  2. Melihat Crash Logs: Buka folder /logs ➔ Buka latest.log. Gunakan pencarian browser (Find in Page) dengan kata kunci ERROR atau Exception.

Multiverse-Core (World Management)

Digunakan untuk mengelola dunia generik (Lobby, Survival, Medieval, Fishing). Jangan gunakan untuk SkyBlock/OneBlock.

1. Membuat World Baru

ConsolePlayer Command
mv create Survival normal
mv create Survival_nether nether
mv create Survival_the_end end
mv create Medieval normal
mv create Fishing normal -g VoidGen

2. Navigasi & Management World

Player Command
/mv tp Survival
/mv setspawn
/mv load Medieval
/mv unload Medieval

Keamanan & Sistem Backup

  • Audit OP Player secara berkala.
  • Gunakan CoreProtect untuk melacak duka/griefing: /co l u:[player] t:1d a:block.
  • Lakukan backup berkala via menu Pterodactyl.

Troubleshooting Matrix

Gejala ErrorAkar PenyebabTindakan PemeriksaanSolusi / Command Fix
1. Server Crash saat Start Versi Java tidak cocok Cek tab Startup Pterodactyl Ubah ke Java 21 / Java 25.
2. Geyser Bedrock gagal Connect Port UDP terblokir Jalankan geyser connectiontest Minta port UDP Allocation tambahan di LavaHosting.
3. Plugin Pancingan/RPG muncul di Survival Belum di-Isolasi Per-World Cek config.yml plugin Tambahkan "Survival" ke disabled-worlds.
