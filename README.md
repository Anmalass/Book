# ZeroCores Master Handbook & World Isolation Guide

Website dokumentasi resmi & panduan isolasi plugin per-world untuk server **ZeroCores (ZeroNest Lobby)**.

## Fitur Utama Web Ini:
- Panduan lengkap isolasi plugin per-world (`disabled-worlds` & LuckPerms World Context).
- Desain modern, responsif untuk browser HP.
- Pencarian cepat & fitur One-Click Copy untuk perintah console/game.

## Cara Deploy ke GitHub Pages:
1. Ekstrak file ZIP ini.
2. Upload seluruh isi folder ke repository GitHub kamu.
3. Buka **Settings** > **Pages** di repository GitHub.
4. Pilih Branch `main` (atau `master`) dan folder `/ (root)`.
5. Klik **Save**.
